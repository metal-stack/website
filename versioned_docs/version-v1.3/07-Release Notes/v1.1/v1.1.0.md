# metal-stack v1.1.0
See original release note at [https://github.com/metal-stack/releases/releases/tag/v1.1.0](https://github.com/metal-stack/releases/releases/tag/v1.1.0)
## General
* [Gardener v1.146](https://github.com/gardener/gardener/releases/v1.146.0)
## Breaking Changes
* The `metal_control_plane_ingress_dns` is not used anymore in the role defaults, everything now defaults to `metal_control_plane_gateway_dns`. We expect you migrated your environment to Gateway API by now. The support for Ingress will be dropped soon. (metal-stack/metal-roles#757)
## Noteworthy
* The `mgmt-firewall` was removed in favor of the new `mgmt-firewall-rutos` role. (metal-stack/metal-roles#747)
