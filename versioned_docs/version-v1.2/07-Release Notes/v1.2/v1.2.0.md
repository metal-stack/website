## Required Actions
* The tenant-apiserver now runs database migrations on startup. For this update, a migration was added that cleans up duplicate membership entries. If you have concerns because you already used memberships a lot, take a look at duplicate membership entries by yourself in the database and decide if you want to cleanup manually.
  
  Here are some queries that show the duplicates:

  ```sql
  SELECT count(*),concat(projectmember->>'project_id','|',projectmember->>'tenant_id','|',projectmember->>'namespace') AS key
  FROM projectmembers
  GROUP BY key
  HAVING count(*) > 1;

  SELECT count(*),concat(tenantmember->>'tenant_id','|',tenantmember->>'member_id','|',tenantmember->>'namespace') AS key
  FROM tenantmembers
  GROUP BY key
  HAVING count(*) > 1; 
  ```
  (metal-stack/tenant-apiserver#11)
