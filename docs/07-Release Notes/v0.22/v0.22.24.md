# metal-stack v0.22.24
See original release note at [https://github.com/metal-stack/releases/releases/tag/v0.22.24](https://github.com/metal-stack/releases/releases/tag/v0.22.24)
## General
* [Gardener v1.143](https://github.com/gardener/gardener/releases/v1.143.0)
## Noteworthy
* `metalctlv2` is now also supported with metal-console. Users of `metalctl` are advised to update as the `--admin` was removed, admins are now detected implicitly by the server. (metal-stack/metal-console#66)
### Required Actions
* metal-console was the has been migrated to use the V2 API. To deploy it, please add the following role to your control plane playbook: `metal-roles/common/roles/metal-v2-client`. The metal-console maintains backwards compatibility with V1, meaning that it is still possible to use `metalctl` for console access as usual. However, at some point, this compatibility will be removed. metal-stack/metal-console#66)
