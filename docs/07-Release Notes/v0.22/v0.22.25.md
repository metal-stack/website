# metal-stack v0.22.25
See original release note at [https://github.com/metal-stack/releases/releases/tag/v0.22.25](https://github.com/metal-stack/releases/releases/tag/v0.22.25)
## General
* [Gardener v1.144](https://github.com/gardener/gardener/releases/v1.144.0)
## Noteworthy
* metal-bmc and pixiecore were migrated to V2. Backwards-compatibility was maintained such that BMC commands and machine allocations can still be run as usual through metal-api. No new role parametrization should be required. (metal-stack/metal-roles#744)
## Required Actions
* Pixie now offers the iPXE build variant `snponly.efi` as an alternative to `ipxe.efi` for machine booting. This variant in general supports more hardware at the cost of performance. You can set the new `--ipxe-type` for configuration. (metal-stack/pixie#48)
* metal-bmc certs were moved to `/etc/metal-bmc`. The old folders `/certs/nsq` and `/certs/console` can be cleaned up manually. (metal-stack/metal-roles#744)
