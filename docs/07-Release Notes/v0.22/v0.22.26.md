# metal-stack v0.22.26
See original release note at [https://github.com/metal-stack/releases/releases/tag/v0.22.26](https://github.com/metal-stack/releases/releases/tag/v0.22.26)
## General
* [Gardener v1.145](https://github.com/gardener/gardener/releases/v1.145.0)
## Noteworthy
* The metal-hammer was migrated to the V2 metal-apiserver. Please make sure the pixiecore from the last release was already deployed with V2, too. Machine allocations through the V1 API still continue to work, so there are no breaking changes for existing clients. (metal-stack/metal-hammer#194)
