# metal-stack v1.3.0
See original release note at [https://github.com/metal-stack/releases/releases/tag/v1.3.0](https://github.com/metal-stack/releases/releases/tag/v1.3.0)
## General
* [Gardener v1.148](https://github.com/gardener/gardener/releases/v1.148.0)
## Required Actions
* Please ensure that all your active firewall images are newer than 2025-01-01, because now the minimum tailscale client version is v1.80.0 (metal-stack/metal-apiserver#354)
## Breaking Changes
* Project and tenant memberships now have own API methods are not wrapped into their parent entities anymore. This allows declarative definition of memberships through CI. (metal-stack/api#196)
* The variables `lo` and `asn` in the `metal-core` role were renamed to `metal_core_loopback_ip` and `metal_core_asn`. (metal-stack/metal-roles#737)
* The `isolated-clusters` role now depends on the new Gateway API v1.6 CRD. Please migrate your Gateway controller to support this version if necessary. (metal-stack/metal-roles#766)
